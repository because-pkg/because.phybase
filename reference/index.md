# Package index

## Phylogenetic Comparative Tools & Diagnostics

Functions for evolutionary models, multi-tree ensembles, and sensitivity
diagnostics.

- [`evo_model()`](https://because-pkg.github.io/because.phybase/reference/evo_model.md)
  : Attach Evolutionary Model Specifications to Phylogenetic Structures

- [`tree_control()`](https://because-pkg.github.io/because.phybase/reference/tree_control.md)
  :

  Configure Multi-Tree (`multiPhylo`) Sampling and Ensemble Options

- [`check_multiphylo()`](https://because-pkg.github.io/because.phybase/reference/check_multiphylo.md)
  : Check Multi-Tree Convergence and Phylogenetic Sensitivity
  Diagnostics

## S3 Methods for Phylogenetic Structures

Methods extending the because engine for `phylo` and `multiPhylo`
objects.

- [`jags_structure_definition(`*`<phylo>`*`)`](https://because-pkg.github.io/because.phybase/reference/jags_structure_definition.phylo.md)
  : JAGS Structure Definition for Phylogenetic Trees
- [`jags_structure_definition(`*`<multiPhylo>`*`)`](https://because-pkg.github.io/because.phybase/reference/jags_structure_definition.multiPhylo.md)
  : JAGS Structure Definition for Multiple Trees (Phylogenetic
  Uncertainty)
- [`prepare_structure_data(`*`<phylo>`*`)`](https://because-pkg.github.io/because.phybase/reference/prepare_structure_data.phylo.md)
  : Prepare Structure Data for Phylogenetic Trees
- [`prepare_structure_data(`*`<multiPhylo>`*`)`](https://because-pkg.github.io/because.phybase/reference/prepare_structure_data.multiPhylo.md)
  : Prepare Structure Data for Multiple Trees
